# Vibe Link

A responsive professional link hub for my engineering portfolio, GitHub projects, and professional network.

## Purpose

Vibe Link provides one focused page for accessing:

- My engineering portfolio
- LogInsightAI
- My GitHub profile
- My LinkedIn profile

## Features

- Responsive mobile-first layout
- Accessible semantic HTML
- Keyboard-visible focus states
- Reduced-motion support
- No JavaScript or third-party runtime dependencies
- Privacy-conscious public links

## Project Structure

```text
vibe-link/
├── index.html
├── styles.css
└── README.md
```

## Run Locally

Clone the repository:

```bash
git clone https://github.com/hnfbyrk/vibe-link.git
cd vibe-link
```

Open `index.html` in a browser. No build step is required.
